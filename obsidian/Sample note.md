## Design principles

The main title stays white; section headings are cyan. **Bold text**, tags, and `inline code` use orange. Yellow is reserved for ==explicit highlights== and important callouts.

- [x] Cyan for links, focus, and active navigation
- [x] Electric blue for structure and code keywords
- [ ] Use ==amber sparingly== for meaningful emphasis

```js
// A small signal in a dark system.
const grid = {
  accent: "#00eeee",
  background: "#030708",
  intensity: 0.12
};
connect(grid);
```

> [!warning] Check the boundary
> Orange identifies warnings, inline code, and numeric values.

> [!success] Connection established
> Success keeps its own color.

> [!error] Connection unavailable
> Errors remain clearly distinguishable from warnings.

> [!important] Key finding
> Important callouts use yellow; question callouts use orange; general information stays cyan.

> [!question]- What happens to a collapsed callout?
> It should remain readable when expanded.
